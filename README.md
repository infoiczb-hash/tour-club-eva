# 🏔️ Турклуб "Эва" - Приключения каждые выходные

Современный веб-сайт для туристического клуба с системой онлайн-регистрации.

## 🚀 Возможности

- ✅ Просмотр расписания мероприятий
- ✅ Онлайн-регистрация на туры
- ✅ Календарный вид
- ✅ Фильтрация по типам (сплавы, походы, велотуры)
- ✅ Админ-панель для управления событиями
- ✅ Многоязычность (RU/EN/RO)
- ✅ Адаптивный дизайн

## 🛠️ Технологии

- NEXT 16/1/6
- Supabase (база данных)
- Tailwind CSS
- Vercel (хостинг)
